# Лабораторна робота №7
## Тема: Приховування методів (new) vs перевизначення (override).
## Варіант: 7. Ієрархія Notification → Email (override) / SMS (new)
* Notification (базовий): virtual void Send(), властивість Message, конструктор.

* Email (похідний): override void Send(), властивість RecipientEmail, конструктор base.

* SMS (похідний): new void Send(), властивість PhoneNumber, конструктор base.


# __Хід роботи:__
Було встановлене середовище розробки VS Code з усіма необхідними розширеннями: C# Dev Kit; .NET Install Tool.
Було створено консольний проєкт lab7v7 у директорії OOP-Khomiak. Відповідно до варіанту створив ієрархію класів Notification, Email та SMS. Клас Notification (базовий) містить властивість Message, конструктор для її ініціалізації та віртуальний метод Send(). Клас Email (похідний) успадковує Notification, додає властивість RecipientEmail, викликає конструктор базового класу за допомогою base() та перевизначає метод Send() за допомогою ключового слова override для забезпечення поліморфізму. Клас SMS (похідний) успадковує Notification, додає властивість PhoneNumber, викликає конструктор базового класу за допомогою base() та приховує метод Send() за допомогою ключового слова new. У класі Program в методі Main() було створено об’єкти всіх трьох класів. Для них продемонстровано виклик методів Send() безпосередньо через змінні власних типів, через посилання базового типу Notification (приведення вгору), а також із використанням явного приведення типів. Результати виконання у консолі наочно довели, що перевизначення (override) забезпечує поліморфний виклик методу похідного класу навіть через посилання базового типу, тоді як приховування (new) викликає метод базового класу.
